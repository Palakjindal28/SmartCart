# 🛒 SmartCart - Online Grocery Delivery Website

SmartCart is a full-stack e-commerce web application built using the MERN stack. It allows users to browse products, add items to cart, place orders, and make secure payments.

---

## 🚀 Features

* 🛍️ Browse and search grocery products
* 🛒 Add/remove items from cart
* 🔐 User authentication (Login/Signup)
* 💳 Secure payment integration (Razorpay)
* 💬 Real-time chat support
* 📦 Order placement and tracking
* ⚙️ Admin features for product and order management

---

## 🛠️ Tech Stack

**Frontend:** React.js, HTML, CSS, JavaScript
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Other Tools:** Razorpay API, Socket.io, Postman

---

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/Palakjindal28/SmartCart.git
```

2. Navigate to project folder

```bash
cd smartcart
```

3. Install dependencies

Frontend:

```bash
cd frontend
npm install
npm start
```

Backend:

```bash
cd backend
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file in the backend folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
RAZORPAY_KEY=your_key
RAZORPAY_SECRET=your_secret
```
